# Engineering Log — Dual-Sensor X7 Radar
**Date:** September 16, 2026

---

## 1. Session Objective

Data collection only — the 2-person occupancy set. There was no engineering
session, no code change and no analysis on this day; everything below is taken
from the recordings themselves and from what later analysis showed about them.

---

## 2. Data Recorded

```
2_people   seats12 / 13 / 14 / 23 / 24 / 34   50 trials each = 300 recordings
           09:15-10:51 (96 min), subject "1", one sitting
           shape (50, 2, 2, 2, 112), 5 FPS, 10 s per trial
```

Each arrangement was recorded as one contiguous block of 50 trials, in the
order seats12 → 13 → 14 → 23 → 24 → 34 (block start times t+6, 27, 43, 64, 77,
90 min into the sitting).

The same person always occupied the same seat on every recording day
(confirmed by the user on Sep 24).

---

## 3. What Later Analysis Showed About This Set

This is the only day with six arrangements, so it became the main test bed for
separating "seat occupancy" from "recording block".

**No instrument drift across the 96 minutes** (Sep 21): correlation between
elapsed time and far-field energy r = +0.11 (p = 0.06, not significant).

**Far-field energy varied by arrangement, not by clock time** (Sep 21):

```
seats12  t+ 6 min  0.0522        seats23  t+64 min  0.0569
seats13  t+27 min  0.0499        seats24  t+77 min  0.0519
seats14  t+43 min  0.0611        seats34  t+90 min  0.0638
```

**Within-day seat detection looked perfect — and was not** (Sep 24):

| test | seat accuracy |
|---|---|
| train on first 75% of every arrangement, test on last 25% | s1 100%, s2 100%, s3 93%, s4 92% |
| hold out one whole arrangement, train on the other five | **49.7%** (chance 50%) |

With an arrangement held out, the model always answered with one of the
arrangements it had already seen. It had learnt to recognise each 50-trial
block (one sit-down), not which seats were occupied.

---

## 4. Consequence for the Dataset

Because every arrangement is one block, **this day contributes 6 independent
sit-downs, not 300 independent samples**. Combined with the other days, v2 has
~16 sit-downs in total — too few for any model with more than a few dozen
parameters to learn a general seat signature.

---

## 5. Lessons

**Fifty repeats of one sit-down are close to one sample.** Nobody stood up
between trials, so every trial of an arrangement shares one exact body
position and one phase fingerprint. The unit of data is the sit-down; the
recording protocol should make people stand and re-seat between trials.
