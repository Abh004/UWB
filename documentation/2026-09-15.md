## 3. Finding — Two Peaks, Not Four

Distinct range peaks per 4-person recording:

```
peaks per recording:  1: 5    2: 29    3: 14    4: 2      mean 2.3
typical peak ranges:  0.69 m and 1.55 m
```

The occupants had been seated **2 in front, 2 behind, front row ~60 cm from the
radar** — a car layout. The two peaks are the two **rows**:

```
0.69 m peak  ->  front row (2 people, bins 27-30)
1.55 m peak  ->  back row  (2 people, bins 39-45)
```

People in the same row sit at the same range and share range bins, so range
alone cannot separate driver from passenger.

The near row also dominates: at R^-4, a person at 0.7 m returns ~340x the power
of one at 3 m (peak SNR 55x vs 3.7x at 3 m).

## 4. Feature Change — AoA Channels Added

A car cabin cannot be staggered, so the features had to improve instead.

The old presence feature was `MTI -> |x|^2 -> mean over TX, RX -> log`. Taking
the magnitude discarded phase; averaging over TX/RX discarded angle. For two
people at one range, total energy was the only remaining cue.

Measured on the 50 recordings, angular information was present:

| region | AoA coherence (&#124;mean phasor&#124;) | reading |
|---|---|---|
| front row | 0.568 | coherent target |
| back row | 0.697 | coherent target |
| far / empty bins | 0.429 | noise reference |

Front and back rows differed by 19° in AoA phase; the per-sensor energy ratio
was 1.13 (front) vs 1.41 (back), a left/right parallax cue.

**Change — `x7_2s_train_presence.py`:** `extract_presence_features` now emits
**10 channels**, 5 per sensor:

```
0,1  log reflected power
2,3  Re horizontal AoA phasor   (TX0/TX1 on RX0)
4,5  Im horizontal AoA phasor
6,7  Re vertical   AoA phasor   (TX0, RX0/RX1)
8,9  Im vertical   AoA phasor
```

`PresenceCNN_X7_Dual` takes `n_channels` (default 10). Verified on the real
recordings: `(10, 50, 92)`, all finite; `x7_2s_live_presence` still imports.

**Stated limitation at the time:** a 2-element aperture resolves ~57°, and the
two front seats subtend ~53° at 0.6 m, so two people in a row cannot be resolved
as two peaks; the AoA channels only add a weaker centroid/coherence cue.

**Later finding (Sep 24):** these absolute-phase channels were exactly what the
CNN memorised. At λ = 41 mm a 1 cm shift of a torso rotates round-trip phase by
~90°, so each sit-down produces a unique, stable phase pattern — a perfect key
for memorisation. See 2026-09-24.md.

## 6. Error Introduced — The Recording Plan

The guidance given today was to record **one occupancy level per sitting**:
"continue with 3", then 2, then 1, then 0, keeping the radar, seats and subject
ID constant. It warned that moving the *geometry* between classes would let the
model learn position instead of count — but it did not warn that recording each
class in its own *session* does exactly the same thing with time.

The consequence (discovered Sep 21): every occupancy level ended up on a
different day, the label was perfectly aliased with the session, and a model
fed only range bins where nobody sits scored 99.7%.

An earlier message the same morning *had* recommended splitting the set across
two sittings so a whole sitting could be held out. That advice was then
superseded by the level-by-level plan instead of being built into it.

## 9. Lessons

**Check the deployment geometry before giving seating advice.** The Sep 11
recommendation to stagger seats in range was physically right and practically
useless — the target is a car. One question ("how will people actually sit?")
would have saved a day.

**A recording schedule is part of the experimental design.** Holding geometry
constant is not enough; *when* each class is recorded is a variable too, and the
plan here confounded it with the label. Every class should appear in every
sitting.
